# Безопасность

Пароли админки — Argon2id. Сессионный token в HttpOnly/SameSite=Strict cookie, в БД только SHA256. Срок 12 часов. CSRF-токен привязан к сессии и проверяется для изменяющих запросов. При HTTPS включите COOKIE_SECURE=true. Rate limit login: десять попыток с IP за пять минут на один backend-процесс. Для масштабирования нужен общий limiter; блокировка не глобальная между несколькими backend.

Никогда не сохраняйте .env, приватные ключи и дампы в Git. Не отправляйте их в чат. AI/Telegram ключи читаются из env и не возвращаются UI. Веб-конфиг секретов и TikTok-пароли не реализованы. Текст описания/исходного комментария отправляется выбранному AI-провайдеру только при запуске генерации оператором.

PostgreSQL/Redis не имеют опубликованных портов. Привязка web по умолчанию loopback. По желанию пользователя прямой HTTP-порт доступен с APP_HOST=0.0.0.0, но HTTP не шифрует cookie и пароль. Ограничьте Security Group своим IP; для доверенного production-доступа нужен HTTPS. Приложение само не открывает Security Group.

Внешние ссылки TikTok валидируются по схеме/домену и не скачиваются сервером. Нет произвольных сетевых URL, SSRF через импорт не поддерживается. Telegram redirect формируется только из invite link, полученного от API. React экранирует пользовательский текст. Дамп restore разрешён только с контролем имени/checksum и в отдельную БД. Content-Length ограничен 256 КиБ; для недоверенного production-трафика нужен также лимит тела на reverse proxy, включая chunked.

Существующие роли и ограничения не заменяют независимый аудит. Интерфейс использует inline runtime Next.js, поэтому CSP допускает unsafe-inline script; это известное ограничение static export. Записи публикаций — отчёты оператора, не независимые доказательства. Приложение не предназначено для обхода правил TikTok и массового рекламного комментирования.
